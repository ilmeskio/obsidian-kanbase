# Add setting to toggle auto scroll when moving to top or bottom

When moving a card to top or bottom, the current behavior is to auto scroll the column to show the card. This behavior proved to be undesired most of the time, since I find myself frequently going through the whole column, checking whether each card should be moved up. When I move one card, I want the scroll to stay where it is, so can I address the next card.

So what I need is a setting that lets the user toggle autoscrolling on/off. This should probably be a global setting in the plugin settings screen.
